## Changes Required

### 1. Modify Top Products Calculation
**Files:** `src/pages/inbox/index.jsx`, `src/pages/inbox/EarningsDetails.jsx`

Update `topProducts` useMemo to collect imageUrl along with name and count:
```javascript
const topProducts = useMemo(() => {
  const productMap = {}
  orders.forEach(order => {
    order.products?.forEach(item => {
      const productName = item.productData?.name || 'Producto desconocido'
      const imageUrl = item.productData?.imageUrl
      if (!productMap[productName]) {
        productMap[productName] = { count: 0, imageUrl }
      }
      productMap[productName].count += (item.stock || 0)
    })
  })
  return Object.entries(productMap)
    .sort((a, b) => b[1].count - a[1].count)
    .slice(0, 5)
}, [orders])
```
